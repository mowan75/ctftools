========================================================
 CTF 杂项解题助手（CTF-Misc-Tool） v1.0.0   使用说明
========================================================

【怎么用】
1. 双击本文件夹里的  CTF-Misc-Tool.exe  即可打开，不需要安装 Python。
2. 把题目文件 / 文件夹直接拖进窗口（也可以点“打开文件”）。
3. 界面是**卡片式**的：每张卡片就是一个功能，左边按题型分好类。
   不确定用哪个就点第一张【全自动分析】，多数题会直接出结果。
4. 右边“flag 候选”里双击即可复制；点“导出报告”可以把全过程存成 Markdown。

【界面结构】
· 左侧：11 个分类、45 张功能卡片（支持右上角搜索框过滤，比如输入 "xor"、"lsb"）
· 右上：flag 候选（双击复制）
· 右中：本次运行的详细结果
· 右下：处理日志（能看到工具每一步做了什么、以及“排除了什么”）

【建议的排查顺序】
先点“全自动分析” → 没出结果就看“结果”面板里哪条有线索 →
再去左侧对应分类点专项卡片（比如“JPEG 系数域”“XOR 爆破”“压缩包伪加密”）→
图片/音频题记得点“图片可视化排查”“频谱图”，很多题答案是看出来的。

【它自己能搞定什么】
· ① 一键分析：整条流水线自动跑完，递归展开所有派生数据
· 文件类型识别、扩展名与真实类型不一致检测、文件内嵌文件雕复（binwalk 精简版，带格式校验不会误报）
· 编码/密码：Base64/32/16/85/58/91、Ascii85、Hex、Hexdump 还原、URL、HTML 实体、
  Unicode 转义、Quoted-Printable、二进制/八进制/十进制、DNA、UUencode、zlib/gzip 内嵌、
  摩斯、培根、A1Z26、Polybius、ROT13/ROT47/凯撒、Atbash、维吉尼亚、栅栏、仿射、
  列置换、键盘错位、字符串反转、自定义字母表 Base64……并且支持多层链式自动解码（A→B→C 全自动）
· 现代密码：**XOR 爆破**（单字节/重复密钥/已知明文反推）、**AES/DES/3DES 解密**（给 key/iv）、
  哈希识别与弱口令爆破、JWT 解码+HS256 爆破、**RSA 弱参数攻击**（小指数/费马/Pollard/共模/Wiener/已知 p,q,phi）
· 古典密码：**维吉尼亚自动破解**（已知明文+频率分析）、**单表替换爬山法求解**、Playfair、Hill、置换类暴力
· 图片：**PNG 宽高爆破（宽/高被改都能列出全部合法尺寸+对照图）**、**Arnold 猫脸变换还原（枚举 1~60 次+对照图）**、**GIF 逐帧分解与帧差图**、**几何变换对照图（旋转/镜像/转置/通道差分）**、**拼图网格切分**、PNG 块结构/文本块/CRC 异常、IEND 后附加数据、JPEG EXIF 与注释、GIF 注释帧数、
  各类 LSB（RGB/BGR/单通道/Alpha/位平面/高低位）、PNG 高度被篡改自动修复、
  两张图异或/相减、内嵌 zlib 流、**图片可视化排查图**（通道分离/位平面/对比度/反相）
· JPEG 系数域隐写（jsteg 类）：直接解出 DCT 系数的最低位数据流，
  支持比特偏移搜索；找不到时会明确告诉你“系数域已检查、没有隐藏数据”
· 压缩包：ZIP 注释、文件名编码（GBK/UTF-8）、**伪加密自动修复**、口令爆破（内置字典+纯数字）、
  zip/gz/bz2/xz/tar/7z 解包、嵌套压缩包递归
· 音频：WAV LSB、频谱图自动生成（若图中藏二维码会自动识别）、DTMF 拨号音、摩斯、MP3 标签
· 二维码：多码识别、放大/反色/二值化增强；也能生成二维码
· 流量包：TCP 流重组、HTTP 对象还原（可直接落盘）、Host 列表、DNS 查询域名、
  USB 键盘击键还原、**USB 鼠标轨迹绘图**（常见“画二维码”）
· 二进制/逆向：**PE/ELF/Mach-O 信息卡**（对标 checksec：位数/PIE/NX/Canary/RELRO/节表熵）、
  **.pyc 反汇编**、**PyInstaller 解包**（解出内嵌 .pyc 与 PYZ 模块并反汇编主脚本）、加壳与反调试线索
· 文本类隐写（新增）：SNOW 行尾空格/Tab、零宽字符（二进制/培根/摩斯/四进制）、Base64 填充位、敲击码、Emoji 编码
· 现代密码补充（新增）：RC4、TEA、XTEA、XXTEA（给 key 直接解，常见于“自写加密”题）
· 取证补充（新增）：SQLite 数据库（遍历所有表/列找 flag）、ICMP 隧道载荷提取（pcap）
· Web 补充（新增）：PHP 伪协议（php://filter、data://、phar://、zip://）与 PHP/Python/Java 反序列化 payload 速查
· 其他：Brainfuck / Ook! / Whitespace 解释器、strings、十六进制查看
· Web 题目（⑫）：站点信息探测（响应头/Cookie/注释/表单/外链）、敏感文件与备份文件扫描
  （先读 robots.txt 找提示）、.git 源码泄露一键恢复、SQL 注入自动检测（报错/布尔/时间/联合查询取 flag）、
  文件包含与路径穿越（多级 ../ + php://filter 读源码）、SSTI 模板注入（8 种引擎）、命令注入、
  HTTP 请求重放器、JS/HTML 源码审计、Web payload 速查表
· 文档与其他（⑬）：PDF 结构与内嵌对象分析、Office 隐藏工作表/内嵌对象取证、
  pyjail 沙箱绕过助手、JWT 伪造（none / 重签）、PHP 弱类型 magic hash 速查

【题库】

【各标签页速查】

⑦ 压缩包 · ⑧ 流量分析 · ⑨ 文件取证 · ⑩ 二进制/逆向 · ⑪ 题库与帮助
⑫ Web 题目 · ⑬ 文档与其他
另外“高级工具面板”卡片会打开经典标签页工具台（编码/图片/压缩包/音频/二维码/其他），
里面可以手动调参数、批量试、把提取结果再喂给自动分析。

【命令行模式】（批量/自动化）
    CTF-Misc-Tool.exe --analyze "题目文件或目录"          分析并生成 分析结果.txt
    CTF-Misc-Tool.exe --analyze "目录" --out 报告.txt     指定输出文件
    CTF-Misc-Tool.exe --selftest                          运行内置自检

【常见问题】
· Web 题怎么用：先跑「站点信息探测」→「敏感文件 / 备份扫描」；扫到 .git 就用「.git 源码泄露恢复」；
  有参数的地方按提示填 URL + 参数名，依次跑 SQL 注入 / 文件包含 / SSTI / 命令注入。
  注意：只能扫你自己有权测试的站点（CTF 靶机、本地靶场），不要对未授权目标使用。
· Web 卡片做不了什么：需要登录态/验证码、复杂绕过链（WAF 绕过、二次注入、反序列化链构造）、
  以及 JS 逆向加密参数这类，需要你自己在浏览器/Burp 里配合。
· 提示“没有直接命中 flag”：看“分析发现”列表里带 ★ 或绿色/黄色的条目，
  或者把可疑数据用 ②③ 页单独再处理一次。
· JPEG 图片没结果：看一下“分析发现”里的「JPEG 系数域检查结果」——
  如果写着“已按 jsteg 规则扫描，未发现文本或 flag”，说明
  ① 图片可能只是普通照片（答案在图里，直接看）；
  ② 或者用了需要口令的 steghide / outguess / jphide / F5，这类要题目给了密码才能解。
· 加密压缩包爆破很久：内置字典 + 0000-9999，命中率覆盖大部分入门题；更复杂的
  需要自己用 hashcat/john 或明文攻击。
· 有些题需要联网/交互（OSINT、pyjail、远程服务），本工具只解决“本地文件型”题目。
· 误报：任何自动化工具都会给候选，最终以题目 flag 格式(`flag{...}`/`xxx{...}`)为准。
